# YourCuteHub 情緒價值小幫手 🐱💕

一個瀏覽器擴充功能（Chrome / Edge，Manifest V3）。安裝後，每個網頁的角落都會住著一隻小可愛，隨時給你滿滿的情緒價值。

## 它會做什麼

| 時機 | 小可愛的反應 |
| --- | --- |
| 打開網頁 | 依早上、中午、下午、晚上、深夜跟你打招呼 |
| 摸摸牠（點一下） | 冒出愛心，再誇你一句 |
| 每隔一段時間 | 主動送上鼓勵（1 秒／10 秒／10 分／25 分／1 小時，或自訂） |
| 打字打很多 | 「打字好認真！」 |
| 複製文字 | 「收集知識中！你好聰明」 |
| 送出表單 | 「又完成一件事了，好厲害 🎉」 |
| 讀完一篇長文章 | 「整篇看完了！好有耐心」 |
| 連續使用很久 | 提醒你起來動一動、看看遠方 |
| 深夜還在上網 | 溫柔催你早點睡 |
| 離開 30 分鐘後回來 | 「歡迎回來！我好想你 🥺」 |

另外：

- 可以拖曳小可愛，換到左邊或右邊、調整高度。
- 滑鼠移上去會出現 ×，可以在這個分頁先把牠藏起來。
- 網頁全螢幕（例如看影片）時自動隱藏，列印時也不會出現。
- 系統開啟「減少動態效果」時會停掉動畫。

## 情緒價值等級

| 等級 | 風格 | 例句 |
| --- | --- | --- |
| 🌙 溫柔 | 安安靜靜陪著你，輕聲細語 | 「慢慢來也沒關係。」 |
| 🌷 暖心（預設） | 溫暖的鼓勵，剛剛好的貼心 | 「你不需要完美，現在的你就很好了 🌸」 |
| 🎉 熱情 | 大聲誇你，每句都附贈愛心 | 「沒有你辦不到的事！衝衝衝 🚀🔥」 |
| 💘 爆表 | 全力寵溺，你就是宇宙中心 | 「你做什麼都對，錯了也是世界的錯 🫶👑」 |

等級越高，泡泡和愛心特效也越熱鬧。

## 設定面板

點瀏覽器工具列上的圖示，可以：

- 開關小可愛
- 選情緒價值等級：溫柔／暖心／熱情／爆表
- 選鼓勵頻率：1 秒、10 秒、10 分、25 分、1 小時，或自訂（秒／分鐘／小時，預設 10 分鐘）
- 選角色：🐱 🐶 🐰 🐻 🦊 🐼 🐧 🐥
- 設定牠怎麼叫你（預設「寶貝」）
- 「更多設定」裡可以調休息提醒、左右位置、行為回饋、深夜提醒，以及不在某個網站出現
- 按「給我一點鼓勵 💖」，馬上收到一句

設定存在 `chrome.storage.sync`，登入同一個瀏覽器帳號的電腦會**雲端自動同步**。收到幾次鼓勵、連續使用時間這類統計只存在本機（`chrome.storage.local`）。

## 安裝（開發者模式）

1. 下載或 clone 這個 repo。
2. Chrome 打開 `chrome://extensions`（Edge 打開 `edge://extensions`）。
3. 打開右上角的「開發人員模式」。
4. 點「載入未封裝項目」，選這個資料夾。
5. 隨便打開一個網頁，右下角就會出現小可愛 🎉

> 安裝前就打開的分頁要重新整理一次，小可愛才會出現。

## 隱私

- 不會連到任何外部伺服器，也不收集你的瀏覽紀錄或輸入內容。
- 打字回饋只「數」你按了幾個鍵，不會讀取內容；密碼欄位不會計算。
- 權限只有 `storage`（存設定）和 `activeTab`（讓設定面板知道目前是哪個網站）。

## 檔案結構

```
manifest.json      擴充功能設定
src/settings.js    預設值、角色清單、讀寫設定（content script 和 popup 共用）
src/messages.js    情緒價值語錄庫，想加新句子改這裡就好
src/content.js     網頁上的小可愛：UI（Shadow DOM）、行為偵測、提醒
popup/             工具列設定面板
icons/             圖示
```

## 自訂語錄

打開 `src/messages.js`，在對應分類和等級（1～4）裡加句子就好，`{name}` 會換成你設定的暱稱。改完到 `chrome://extensions` 按重新載入。
